# Roadmap

## Current Focus

The current implementation target is V1/V2.

The product has two surfaces:

- Owner Dashboard for authenticated merchant internal users.
- Shopify Customer Chat Widget for unauthenticated storefront customers.

## V1: Basic AI Assistant

V1 should deliver:

- Authenticated owner dashboard.
- Basic document upload and ingestion.
- Internal vs public document visibility.
- Public Shopify widget configuration.
- Customer-safe Shopify widget chat.
- Basic dashboard chat.
- Basic read-only dashboard tools for products, orders, and sales.

## V2: Smart Assistant

V2 should improve:

- Hybrid retrieval.
- Metadata filtering, including visibility filtering.
- Query rewriting.
- Multi-document customer-safe widget answers.
- Multi-tool dashboard agent summaries.

## Future Work

Do not design these in detail yet:

- Shopify OAuth app installation.
- Shopify billing.
- Shopify webhooks.
- Business action execution.
- Human approval workflows.
- Autonomous monitoring.
- Scheduled tasks.
- V3-V6 agent capabilities.
